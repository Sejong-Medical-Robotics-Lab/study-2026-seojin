# 학습일지 — 2026-07-31 (Week 2, Go2)

## 배운 내용

- **Go2**
  - 관절 모터 × 12 (고관절 2 + 무릎 1로 다리당 3자유도)
  - 4D LiDAR, 전방 카메라, IMU, 내장 컴퓨터, 배터리
  - 다리: FL, FR, RL, RR
  - 보행 패턴: walk, trot, bound
  - 명령 계층: low-level, high-level
  - 대표 동작
    - StandUp
    - StandDown
    - Move(vx, vy, vyaw)
    - StopMove
    - BalanceStand
  - 토픽 지도
    - 속도 명령(Twist 계열): 내 코드 → Go2
    - 보행 상태, LiDAR PointCloud, 관절 상태, 카메라 영상: Go2 → 내 코드
  - Odometry: GPS가 없는 실내에서 로봇이 이동량을 적산하여 위치를 추정
  - 조사 도구
    - `ros2 topic hz <토픽>`
    - `ros2 topic bw <토픽>`
    - `ros2 topic echo --no-arr`
    - `ros2 bag record <토픽들>`
  - Gazebo
  - RViz2
  - LiDAR(PointCloud)

## 직접 해본 것 / 성공한 것

- Gazebo를 이용한 Go2 사족보행 로봇 시뮬레이션
- 시뮬레이션에서 Go2 이동
- Gazebo에 장애물 추가하여 환경 구성
- RViz에서 RobotModel과 LiDAR(PointCloud) 시각화 확인

## 막혔던 것

- Ubuntu 24.04 환경에서는 Gazebo를 바로 실행할 수 없어 컨테이너를 생성한 후 실행해야 했다.
- Gazebo 실행 후 RViz에서 처음에는 로봇 모델이 나타나지 않아 원인을 해결하는 데 시간이 오래 걸렸다.

## 한 줄 소감

Go2를 처음 다뤄보며 Gazebo와 RViz를 활용한 시뮬레이션을 직접 경험하고, 지난주에 배운 ROS2를 실제로 적용해 보며 이해를 높일 수 있었다. 이번에는 high-level 제어의 기초를 익혔는데, 앞으로는 다양한 기능과 low-level 제어도 직접 구현해 보고 싶다.
